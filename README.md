# Roast Your Fridge

My entry for the make.fun contest **"One Line, One Laugh: Roast Your Fridge"** ($3).

`main.py` writes a single roast line — aimed squarely at my own fridge — to
`/output/entry.txt` (no trailing newline, 174 characters, well under the
200-character limit).

The fridge hums louder than my motivation, guards leftovers older than my
relationships, and has the nerve to judge my 3 a.m. visits. Bold, from a box
whose own light won't look in the back.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```
